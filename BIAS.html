Project: BIAS

An improvising musical companion

Written Documentation

Basically BIAS is supposed to be a companion to me when playing woodwinds. I'm a musician that works with improvisation as my main method for making music. Everything is done in SuperCollider, except for adding some minor post-production on the clarinet sound in a DAW.

I am very inspired by early Swedish electronic music. I'm terrible at doing music using sequencers. I like impulses(emotional, not electric). I like white noise, filters and sine waves and what you can do with some simple cooking.

BIAS can be divided into four steps.

It receives sound from an audio input. It then has what I call a slow listener. It gives an output that answers "How have I've been playing recently?". this is tricky and not perfect at all. But it gives me a value(0-1) that answers how active I've been lately. So if I have played a lot, then it gives me 1, if I have been mostly silent -> 0. This can function as an LFO for other parameters during performance. Then there is a simple sample recorder and a sample playback. I use an IntraMic from Viga Tools to get a signal with almost zero noise and no feedback.

Both audio and data goes into the heart of the system. Here I use my modules/synths. Instead of having synths that I control using midi or controlling by a graphic interface, I feed data to the synths. Amplitude, pitch-info, spectral centroid and flatness are used to trigger sound, changing sound, changing pitch, triggering calculations for various stuff. Most of the modules also has a slight generative, or independent, behaviour built in. This is so that the modules do not depend on me to play themselves. All of these modules sum up to a shared signal that then goes in to the fx chain. I'm not an expert on synthesis or synth design. So the library is growing and changing a lot.

Im not interested in creating a loop station for my clarinet. So the clean clarinet signal is not going past the modules. If I sample something, it is mostly the processed signal. And then I can feed that sample in to the modules again. This can create some really fun layers.

The synths go into an FX chain. The fx-chain system allows me to click-free(almost) swap the order of effects. This opens up for some fun experiments. It started out with the idea to have like a pitch shifting reverb. Usually when I design effects for my music in SuperCollider I try to achieve these big effects that have a lot of different functions. Someone at sccode.org posted this sitar-synth which split the instrument into the attack(finger/pick), the string, the resonator and the room. I started messing around with this and realized this was way smarter than building a one-piece synth. So what I did was to divide my pitch shifting reverb into three parts. The delay, the pitch and the time. Later, I added a blur as well. Then I started experimenting with shifting the order of these things and got some very fun sound. I then added a binshift, a formant and some echo and feedback delays. Then I added some functionality so that I could swap the order really quick and easy. And I centralized the whole system so that I use 4 macros to control all of the effects. Chaos, density, space and identity.

The last part is just a synth that can do some spatialisation. Autopanning, and expand the system to a multichannel setup. Every chain has it's own spatial synth. This makes it possible to create some fun movements in a live setup.

I control the system using a Morningstar MC6 foot pedal and a Faderfox UC4 midi controller. Mostly I just set a "mood". This is like a preset. It includes which modules to choose, some base values for the parameter, the fx-chain and some presets there to. The idea is to have some kind of control of the system. There is no price for me if I have a completly indepedent system. Just as long as it is fun to play with and sounds good. The fun comes from getting a lot of inspiration when playing. So with my physical controllers I can sample either the clean recording or the sound from the modules. I can choose a mood. I can choose if the mood is going to follow my playing or counter it. I can also make some mixing if necessary and I can change the parameters if it sounds bad or not fun enough. I can also use an expression pedal to morph between different parameter values for the modules.

(
(
~soundcheck = {
    Routine({
        var noiseReadings = [], sustainReadings = [], attackReadings = [];
        var noiseFloor, sustainFloor, attackFloor, percentileIndex;
        var soundchecksynth;
        var bus = ~bus[0].ctl.scAmp; // Use your own name for this bus. Then you should not have to change too much in this code. 


        soundchecksynth = Synth(\soundCheck, [\in, ~bus[0].raw, \ampBus, bus], ~fbs[0][\firstGroup], \addToTail); // change busses to whatever you use. You can also add a sendReply to a synthdef with just an SoundIn and Amplitude. 

        "--- STEP 1: SILENCE (4s) ---".postln;
        "Don't move or blow...".postln;
        80.do {
            noiseReadings = noiseReadings.add(bus.getSynchronous.postln); 0.05.wait;

        };

        noiseReadings = noiseReadings.sort;
        percentileIndex = (noiseReadings.size * 0.95).floor;
        noiseFloor = noiseReadings[percentileIndex];
        "Result -> Noise Floor: %".format(noiseFloor.round(0.0001)).postln;

        2.wait;
        "--- STEP 2: SOFT SUSTAIN (4s) ---".postln;
        "Play your softest stable long note...".postln;
        80.do { sustainReadings = sustainReadings.add(bus.getSynchronous.postln); 0.05.wait; };
        // We take the median of your playing to find the stable center
        sustainFloor = sustainReadings.median;
        "Result -> Soft Sustain: %".format(sustainFloor.round(0.0001)).postln;

        if (noiseFloor >= (sustainFloor * 0.8)) {
    "WARNING: High noise detected. Adjusting gate for safety.".postln;
    noiseFloor = sustainFloor * 0.5; // Force the gate to be half the volume of a note

            ("noiseFloor set to: "++noiseFloor).postln;
};

        2.wait;
        "--- STEP 3: ATTACK HITS ---".postln;
        "Play 5 short staccato notes at comfortable volume...".postln;
        80.do {
            var val = bus.getSynchronous.postln;
            if(val > (sustainFloor * 2)) { attackReadings = attackReadings.add(val) };
            0.05.wait;
        };
        attackFloor = if(attackReadings.size > 0) { attackReadings.median } { sustainFloor * 2 };
        "Result -> Attack Median: %".format(attackFloor.round(0.0001)).postln;

        // --- CALCULATE SYSTEM VALUES ---
        // 1. Listen Threshold: Halfway between noise and softest note
        ~sysNoiseLimit = (noiseFloor + sustainFloor) / 2;

        // 2. Trigger Threshold: Just below your attack hit
        ~sysTrigLimit = attackFloor * 0.7;

        "--- CALIBRATION COMPLETE ---".postln;
        "Updating System...".postln;

        // Apply to running synths
        ~fbs[0][\listen][\synth].set(\noiseFloor, noiseFloor * 1.02); // It is good to store this in a dictionary. Create one! 
        ~fbs[0][\data][\synth].set(\ampFloor, attackFloor * 0.65);

        // Save to modParams for future modules
        ~fbs[0][\ampFloor] = (noiseFloor + sustainFloor) / 2;
        ~fbs[0][\softAmp] = sustainFloor * 0.9;
        ~fbs[0][\atkThresh] = attackFloor * 0.7;

        soundchecksynth.free;
        ~soundchecked = true;

    }).play;
};

// --- Create a new FX chain
~newFXChain = {
    ~dbg.("newFXChain", "creating new chain");
    (
        group: Group.before(~spatialGroup),
        synths: Array.new,
        buses: Array.new,
        outBus: nil,
        //spatialSynth: nil;
    )
};

// --- Ensure enough buses for the FX chain
~ensureFXBuses = { |chain|

    var needed = (chain[\synths].size - 1).max(0);

    // Free all existing buses
    chain[\buses].do(_.free);

    // Create exactly the number we need
    chain[\buses] = Array.fill(needed, {
        Bus.audio(s, 1)
    });

    ~dbg.("ensureFXBuses", "rebuilt buses, count: " ++ chain[\buses].size);
};


// --- Get or create an FX synth
~getOrCreateFX = { |chain, defName, index, inBus = nil, outBus = nil|
    var s;
    ~dbg.("getOrCreateFX", "request: " ++ defName);
    s = chain[\synths].detect { |x| x.defName == defName };
    if (s.isNil) {
        ~dbg.("getOrCreateFX", "creating synth: " ++ defName);
       s = Synth(defName, [\in, -1, \out, -1], chain[\group], \addToTail);
        chain[\synths].add(s);



    } {
        ~dbg.("getOrCreateFX", "reusing synth: " ++ defName);
    };

    if (defName == \bufgrain) {
    s.set(\buf, ~grainBuf[index]);
        ~dbg.("getOrCreateFX", "setting grainbuf to index: " ++ index)
};
    s;
};

// --- Order FX synths in a chain
~orderFX = { |chain, orderedSynths|
    ~dbg.("orderFX", "ordering: " ++ orderedSynths.collect(_.defName).join(" → "));
    orderedSynths.do { |s| s.moveToTail(chain[\group]); };
    chain[\synths] = orderedSynths;
};


// --- Wire FX chain
~wireFXChain = { |index, chain|

    var synths = chain[\synths];
    var buses  = chain[\buses];
    var lastIndex;

    if (synths.isEmpty) { ^nil };

    lastIndex = synths.size - 1;

    synths.do { |s, i|

        var inBus, outBus;

        if (i == 0) {
            inBus = ~bus[index].fxIn;
        } {
            inBus = buses[i-1];
        };

        if (i == lastIndex) {
            outBus = ~bus[index].fxOut;
        } {
            outBus = buses[i];
        };

        if (inBus.isNil or: { outBus.isNil }) {
            ("Routing error: nil bus at index " ++ i).warn;
        };

        s.set(\in, inBus, \out, outBus);

        ("FX " ++ i ++ " [" ++ s.defName ++ "] IN: "
            ++ inBus ++ " OUT: " ++ outBus).postln;
    };
};



~freeFX = { |index|
    var chain = ~fxChain[index];
    if (chain.notNil) {
        chain[\synths].do { |fx| fx.set(\gate, 0); };
        chain[\buses].do(_.free);
        //~sendBus[index].free;

        chain[\group].freeAll;
        chain[\group].free;
    };
    ~fxChain[index] = nil;
};



~updateFXChain = { |index, newFXOrder, outBus|
    var chain, oldSynths, newSynths, toKeep, toRemove, toAdd, finalSynths, synth, lastFX;

    chain = ~fxChain[index] ?? { ~newFXChain.() };
    ~fxChain[index] = chain;

    oldSynths = chain[\synths];

    toKeep   = oldSynths.select { |s| newFXOrder.includes(s.defName) };
    toRemove = oldSynths.reject { |s| newFXOrder.includes(s.defName) };
    toAdd    = newFXOrder.reject { |key| toKeep.any { |s| s.defName == ~fxDict[key] } };

    // --- remove old FX not in new order
    toRemove.do { |s| s.set(\gate, 0, \fbEnable, 0); };

    // --- create new FX
    newSynths = toAdd.collect { |key|
        synth = ~getOrCreateFX.(chain, ~fxDict[key], index);
        synth.set(\fbEnable, 1);
        synth;
    };

    toKeep.do { |s| s.set(\fbEnable, 1); };

    finalSynths = newFXOrder.collect { |key|
        (toKeep ++ newSynths).detect { |s| s.defName == ~fxDict[key] }
    };

    ~orderFX.(chain, finalSynths);
    ~ensureFXBuses.(chain);

    // --- Wire FX chain (first synth -> last FX -> sendBus)
    ~wireFXChain.(index, chain, ~bus[index].fxIn, ~bus[index].fxOut);

 /*  // --- Make sure last FX sends to sendBus, spatial reads from sendBus
    if(chain[\synths].notEmpty) {
        lastFX = chain[\synths].last;
        lastFX.set(\out, ~bus[index].fxOut);
    };*/


    ~prc.applyPerceptToChain(index);
    ~dbg.("updateFXChain", "update complete for chain " ++ index);

};





// --- This is the only command you will use, and ~fxFree.
~fx = { |index, fxOrder, outBus|
    ~updateFXChain.(index, fxOrder, outBus);
};

~fxSet = { |index, fxKey, args|
    var chain, synth;

    chain = ~fxChain[index];
    if (chain.isNil) {
        ("fx" ++ index ++ " no chain").warn;
        ^nil;
    };

    // --- Normal FX
    synth = chain[\synths].detect { |s|
        s.defName == ~fxDict[fxKey]
    };

    if (synth.isNil) {
        ("fx" ++ index ++ " no synth: " ++ fxKey).warn;
        ^nil;
    };

    synth.set(*args);
    synth;
};
