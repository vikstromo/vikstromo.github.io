Did some experiments with a new function that listen and react a little bit different than my other functions. This functions solves some issues that I've had when performing with the system. The biggest issue has been that I have to manually make it change behaviour and have different mechanisms that listen. 

So the brain is to parts. The ~fb.otherbrain and the ~fb.brainChoice. 
All the measurements are done in ~fb.otherbrain and then ~fb.brainChoice makes musical choices. What fb.otherbrain does is to try and categorize a phrase in some way. It says if a phrase is "long notes" or "rhytmic" or "noisy" or "gesture like". 


The code runs every 0.05 seconds ($20Hz$). In every tick, it fetches five critical values from your control buses: Amplitude, Trigger (onset), Pitch, Spectral Flatness, and Centroid.

Then it checks:
- First Note: If it wasn't already listening, it marks the startTime, resets all data lists (pitchList, etc.), and posts "> Listening...".

- Feature Tracking: It continuously appends data to flatList and centList.

- Pitch Filtering: It uses a Ratio Check. It only records pitches that are between 0.35x and 3.0x of the previous note. This filters out octave glitches while still allowing for wide expressive sweeps.

- Onset Counting: It watches curTrig. Every time a new "attack" is detected, noteCount increases. This works quite poorly. Even if I have put 100s of hours trying to get triggers to work nice, I still have a lot of issues with multiple triggers and jitter.

Then I have this silenceGrace that basically makes every phrase end with approx 2 seconds of silence before posting a message on what kind of phrase it heard. This is because I usually dont play like 1 bar or 2 bars. But open phrases where I mix stuff up. It then answers some questions.

    - How long was the avg duration of a note? 
    - How dense was the phrase?
    - Was it noisy?
    - How much did the frequency spread ?

Then it answers: 
Rhythmic: Many notes, short durations.

Noisy/Breath: High spectral flatness or high centroid.

Gesture: Wide pitch range (over 1.5 octaves).

Melodic: Moderate pitch range and duration.

Long Steady: Long duration but low note count.
