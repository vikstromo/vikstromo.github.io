This is a project linked to the BIAS-system. But here I wanted something more coventional but still being tactile for me as a wind instrument player. I read about Tom Kesslers guitar box at the Bela blog and tried to achive something similar. The box has a looper that can overdub, stutter,scrub and granulate. It has an FM-synth that I borrowed from Daniel M Karlssons SuperClean. It also has a drum-machine that uses Björklund/Euclidean rhytmic layers. It has a delay that goes into a filter and then a reverb. The clarinet goes through a different delay and filter and it is 100% wet so that the machine sounds good in small spaces. So the clarinet is not amplified, but mixed in to the machine sound. Hopefully I will be able to build a box using a Bela Gem Stereo and some Trill sensors. I have never worked with hardware, so it will be interesting to see what I can do.
